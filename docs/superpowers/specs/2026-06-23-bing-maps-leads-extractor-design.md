# Bing Maps Leads Extractor 設計

## 目的

社内利用向けのChrome拡張機能として、Bing Mapsの検索結果から最大500件の事業者情報を収集し、CSVまたはExcelで出力できるツールを提供する。

外部サーバー、ログイン、課金、外部APIは使用しない。収集データと処理状態は利用者のブラウザ内だけに保存する。

## 対象範囲

### 対応するもの

- デスクトップ版Bing Maps
- Bing Maps内に表示するサイドパネル
- 検索結果の自動スクロール
- 店舗詳細画面の順次解析
- 最大500件の収集
- 一時停止、再開、停止
- 途中状態の保存と復元
- 重複除去
- CSV出力
- Excel出力
- 日本語および英語の検索結果

### 対応しないもの

- Google Maps
- 企業Webサイトの巡回
- Bing Mapsに表示されていないメールアドレスやSNSの探索
- クラウド同期
- 複数ユーザー管理
- 課金、認証、利用量管理
- 営業メールの自動送信

## 取得項目

各事業者について次の項目を保存する。Bing Mapsに情報がない項目は空欄とする。

- 店名
- カテゴリ
- 住所
- 電話番号
- Webサイト
- メールアドレス
- SNS
- 緯度
- 経度
- 評価
- 口コミ数
- 画像URL
- Bing Maps URL

## 操作フロー

1. 利用者がBing Mapsで地域と業種を検索する。
2. Bing Maps画面内のサイドパネルで最大取得件数を指定する。初期値は500、上限も500とする。
3. 利用者が「取得開始」を押す。
4. 拡張機能が検索結果一覧をスクロールし、結果URLを収集する。
5. 各結果を順番に開き、詳細画面から取得可能な情報を解析する。
6. 取得結果、進捗、スキップ数、エラー数をサイドパネルに随時表示する。
7. 利用者は処理を一時停止、再開、停止できる。
8. 完了後または途中停止後、取得済みデータをCSVまたはExcelで出力できる。

## アーキテクチャ

拡張機能はManifest V3で構成する。

### Content Script

- Bing Mapsページへサイドパネルを挿入する。
- 検索結果一覧と店舗詳細のDOMを解析する。
- 自動スクロールと店舗遷移を制御する。
- 進捗をUIへ反映する。
- DOM解析処理は画面制御から分離し、Bing Mapsの構造変更に追従しやすくする。

### Background Service Worker

- タブ単位の実行状態を管理する。
- Content Scriptから受け取った事業者データを保存する。
- CSVおよびExcelファイルのダウンロードを開始する。

### Chrome Storage

- 実行設定
- 収集済みデータ
- 処理中の結果位置
- 一時停止状態
- エラー統計

データは`chrome.storage.local`へ保存する。検索途中でページを閉じても、同じ検索を再開できる状態を保持する。

### Exporter

- CSVはUTF-8 BOM付きで生成し、日本語版Excelでの文字化けを防ぐ。
- ExcelはSheetJSを拡張機能内へ同梱して生成する。
- CSVインジェクション対策として、`=`, `+`, `-`, `@`で始まる値を無害化する。

## データフロー

1. Content Scriptが検索結果の候補を検出する。
2. 未処理の候補を1件開く。
3. 店舗詳細が表示されるまで待機する。
4. Parserが各項目を抽出する。
5. 正規化したデータを重複判定する。
6. 新規データをStorageへ追加する。
7. UIへ進捗を反映する。
8. 次の候補へ進む。

## 重複判定

次の順序で一意性を判定する。

1. Bing Maps URLまたはBing固有ID
2. 正規化した店名と住所の組み合わせ
3. 正規化した店名と電話番号の組み合わせ

文字列は前後空白、連続空白、全角・半角差、電話番号の記号を可能な範囲で正規化する。

## エラー処理

- 店舗詳細が一定時間内に表示されない場合は最大3回再試行する。
- 一部項目だけ取得できない場合は空欄として保存し、処理を継続する。
- 同じ結果一覧位置で進展がない場合は、スクロールを数回再試行する。
- 一定回数再試行しても新しい結果が増えない場合は、検索結果の終端として正常終了する。
- DOMの主要要素を検出できない場合は「Bing Mapsの画面構造が変更された可能性があります」と表示して停止する。
- 停止時には処理中データを破棄せず、取得済み結果を出力可能にする。
- 拡張機能自身が生成したUIはShadow DOM内に置き、Bing MapsのCSSとの衝突を避ける。

## 負荷制御

- 店舗を開く処理の間に待機時間を設ける。
- DOMの変化を監視し、固定時間待機だけに依存しない。
- 同時並列では取得せず、1件ずつ処理する。
- CAPTCHA、アクセス制限、異常なリダイレクトを検出した場合は自動停止する。

## 権限

必要最小限の権限だけを使用する。

- `storage`
- `downloads`
- Bing Mapsに限定したhost permission

閲覧履歴全体、Cookie、クリップボード、外部サイトへのアクセス権限は要求しない。

## テスト方針

### 単体テスト

- 店舗情報Parser
- URLおよび座標Parser
- 口コミ数・評価値の正規化
- 重複判定
- CSVセル無害化
- CSVおよびExcelの列生成

### ブラウザテスト

- 1件、100件、500件の取得
- 日本語および英語検索
- 情報が欠落した店舗
- 一時停止、再開、停止
- ページ再読み込み後の復元
- 検索結果の終端判定
- CSVとExcelの日本語表示
- Bing Mapsのレイアウト差異

## 完了条件

- Bing Mapsの検索結果から最大500件を順次処理できる。
- 指定された全項目を、表示されている範囲で保存できる。
- 一時停止、再開、停止が機能する。
- ページ再読み込み後も取得済みデータを失わない。
- 重複データを出力しない。
- CSVおよびExcelを正常に開ける。
- 外部サーバーへデータを送信しない。

## リスクと保守

Bing MapsのDOM構造は予告なく変更される可能性がある。Parserとセレクターを独立したモジュールにまとめ、画面構造変更時の修正範囲を限定する。

本ツールは社内利用を前提とし、Bing Mapsの利用条件、アクセス制限、適用される個人情報・営業活動関連法令を利用者側でも確認する。自動取得を保証する公式APIではないため、継続的な動作確認と保守が必要になる。
